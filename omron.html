Brief

Omron is an electronics company based in Kyoto, Japan. The QBurst experience team was asked to design new features for Omron's existing healthcare mobile app.

Challenge

The app already had a strong UI, so adding new features without disrupting it was the challenge.

My role

I led the visual design team to find a solution to the client's needs.

New features

Blood pressure graphs

The requirement – add a graph to the existing blood pressure monitor screen.

Activity timeline

The requirement – add options to view a graph, share and delete an activity.

Activity timeline tutorial

The requirement – add walkthrough screens for the new features.

Edit profile

The requirement – add screens to edit the profile.

Conclusion

What would I do next?

With more time, we could have built a prototype and run user testing to see how users react to the new features.
